# Fotos de estoque

Diretriz homologada: fotografias reais aparecem somente no módulo de Estoque.

Quando as fotos reais forem disponibilizadas, salvar os arquivos nesta pasta e preencher `imageUrl` nos itens de `src/data/mock/jaguar.ts` (durante a fase mock) ou retornar a URL pelo backend no Marco 3.

Exemplo: `/images/stock/colmeia-caminhao-001.webp`.
